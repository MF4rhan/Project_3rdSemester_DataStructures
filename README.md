# Huffman File Compression

## 1. Project Overview

This project is a file compression and decompression program written in C++ using the Huffman Coding algorithm.

Huffman Coding is a lossless compression technique. It assigns shorter binary codes to frequently occurring characters and longer codes to less frequent characters.

The goal is to reduce file size while ensuring that the original file can be recovered exactly.

The program supports all 256 possible byte values, so it can work with binary files as well as text files.

## 2. Project Structure

| File | Description |
|---|---|
| `main.cpp` | Runs the program and connects all modules |
| `Node.h / Node.cpp` | Defines the nodes used in the Huffman tree |
| `MinHeap.h / MinHeap.cpp` | Implements the minimum heap used to build the tree |
| `HuffmanTree.h / HuffmanTree.cpp` | Builds the Huffman tree, generates codes, and saves the tree structure |
| `Compression.h / Compression.cpp` | Compresses the original file |
| `Decompression.h / Decompression.cpp` | Decompresses the compressed file |

## 3. Team Responsibilities

### Member 1: Huffman Tree Construction
- Reads the input file and counts the frequency of each byte.
- Creates the initial leaf nodes.
- Uses a manually implemented minimum heap to build the Huffman tree.
- Generates a binary code for each byte.
- Serializes the Huffman tree so it can be reconstructed later.

### Member 2: Compression
- Uses the Huffman codes generated by Member 1.
- Reads the original file and replaces each byte with its corresponding binary code.
- Packs the resulting bits into bytes.
- Writes the compressed data, tree information, and necessary metadata into a file.

### Member 3: Decompression
- Reads the compressed file.
- Reconstructs the Huffman tree using the saved tree information.
- Reads the compressed bits and decodes them using the tree.
- Writes the recovered data into a new file.

## 4. How the Program Works

The general process is:

1. Count the frequency of each byte in the original file.
2. Build the Huffman tree using a minimum heap.
3. Generate Huffman codes from the tree.
4. Encode the original file using those codes.
5. Save the tree and compressed data.
6. Reconstruct the tree during decompression.
7. Decode the compressed data to recover the original file.

## 5. Huffman Tree Serialization

The tree is saved using preorder traversal (root, left, right).

Two marker values are used:

- `0`: Represents an internal node.
- `1`: Represents a leaf node. The next byte stores the character in that leaf.

This allows the decompression module to rebuild the original tree without needing the frequency table.

## 6. Compressed File Format

The compressed file contains three main sections:

1. **Metadata:** Stores information such as the original file size or number of valid compressed bits.
2. **Serialized Huffman Tree:** Stores the structure of the Huffman tree.
3. **Compressed Data:** Stores the encoded bits packed into bytes.

All team members must use the same file format so that compression and decompression work together correctly.

## 7. Important Considerations

- The program supports all 256 possible byte values.
- Files must be opened in binary mode.
- Empty files must be handled.
- Files containing only one unique byte must be handled.
- Padding bits added to the final byte must be ignored during decompression.
- The decompressed file must be identical to the original file.

## 8. Compilation

Compile all `.cpp` files together.

Example using g++:

```bash
g++ main.cpp Node.cpp MinHeap.cpp HuffmanTree.cpp Compression.cpp Decompression.cpp -o Huffman
```

## 9. How to Run the Project

### Requirements
- Visual Studio with C++ desktop development tools installed.
- The project solution file (`.sln`).

### Running in Visual Studio

1. Clone or download the GitHub repository.
2. Open `HuffmanProject.sln` in Visual Studio.
3. Select the `Debug` configuration and `x64` platform.
4. Make sure the Huffman project is selected as the Startup Project.
5. Set the working directory to `$(ProjectDir)` under Project Properties → Configuration Properties → Debugging.
6. Place the input file in the project directory (the directory containing the `.vcxproj` file).
7. Press `Ctrl + F5` to run the program.


### 10. Important Notes

- Input and output files should use different filenames.
- Files must be opened in binary mode.
- The input file must exist in the program's working directory if only a relative filename is provided.
- The compressed file contains the information needed to reconstruct the Huffman tree.
- The decompressed output should be identical to the original file.
